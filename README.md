# Library Management System

A desktop-based Library Management System developed using Java Swing,
JDBC, and SQLite.

This project was created through **vibe coding with AI-assisted development**.

## Features

- Book Management
- Student Management
- Add, Update, Delete and Search Books
- Add, Update, Delete and Search Students
- Book Issue Management
- Book Return Management
- Issue Date and Return Date
- Late Fee Calculation
- Book Availability Tracking
- Dashboard
- SQLite Database
- JDBC Connectivity

## Technologies Used

- Java
- Java Swing
- JDBC
- SQLite

## Project Type

Desktop Application

## Database

SQLite database is used to store:

- Books
- Students
- Issue/Return records
